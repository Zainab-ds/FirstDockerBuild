# 🚀 My First Dockerized Flask App

This is my first project using Docker with Flask. It may be a simple application, but building it taught me a lot about Docker, containerization, and solving real-world errors along the way.

## 🛠️ Tech Stack

* Python
* Flask
* Docker 
## ▶️ Run the Project
-->In command prompt 
1 :docker build -t myfirst_image .
2 :docker run -p 5000:5000 myfirst_image
3 :Then open:
4 :http://localhost:5000
## 📚 What I Learned

* Creating a Dockerfile
* Building and running Docker images
* Port mapping
* Basic Flask deployment with Docker

*Every error was a lesson, and this project is the first milestone in my Docker journey.* 🚀
